SOBRE

O que é Master Nerd?

Master Nerd é um toolkit desktop moderno com interface retrô arcade. Perfeito para quem quer uma ferramenta prática com estilo dos anos 80/90.

Características Técnicas

  • ✨ Built com Electron + Node.js
  • 🎨 UI com efeitos CRT autênticos
  • 📦 Distribuição como executável portable
  • 🔒 Seguro e sem dependências externas
  • 🚀 Rápido e responsivo

Como Usar

  1. Baixe o arquivo .exe acima
  2. Execute diretamente (sem instalação)
  3. Aproveite a interface retrô!
